# 説明資料_PAI最終課題（草稿）

## 1. 課題の概要と目的
- 自然言語指示でCRANE+ V2にピック&プレースを行わせる。LLMが計画、ROS2ノードが実行、失敗時に再計画する閉ループ。

## 2. システム構成
- 図: 指示 → Planner(LLM) → Controller(IK) → Gazebo/CRANE+ V2 → Perception → Monitor → (失敗時)Planner
- 使用ツール: ROS2 Humble, Gazebo, crane_plus packages, Claude API

## 3. 工夫した点
- LLM出力をJSONの固定語彙に限定し、到達範囲チェックで物理的に不可能な計画を弾く安全層
- Monitorによる到達判定と再計画（人が物体をずらしても完遂）
- 会話履歴を保持し「さっき置いた場所に戻して」等の参照指示に対応
- LLMを制御ループの外に置くイベント駆動設計（遅延の影響を受けない）

## 4. デモ内容（動画の構成）
1. 構成説明 2. 基本ピック&プレース 3. 曖昧指示（色ごとに仕分け） 4. 妨害からの回復 5. まとめ

## 5. 結果と考察
- 成功/失敗の回数、再計画の回数

## 6. 反省点・今後の発展
- 世界モデル(学習した動力学)＋MPCによるController置き換え
- toio（非把持・押し運び, Push-T相当）への同一アーキテクチャの移植
- VLMによる知覚（Gazebo真値からの脱却）
